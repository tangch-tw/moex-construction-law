# 普考建築工程「營建法規概要」歷屆試題複習系統

公務人員普通考試建築工程類科「營建法規概要」104–115 年歷屆試題之隨機練習與自我評分網頁。純靜態網頁，可直接掛在 GitHub Pages，學生開網址即用，免登入、免安裝、免後端。

---

## 一、功能

| 需求 | 實作方式 |
|---|---|
| 學生透過網頁連線 | 靜態 HTML，GitHub Pages 提供網址 |
| 系統封面與科別導覽 | 封面置中國科技大學校徽與「規劃與設計學院　建築系」，點擊進入後依「考試等別 → 應試科目」兩層選單進入題庫；每頁右上角固定顯示藍色校名系名字樣 |
| 亂數每次出一題 | 依「練習模式／年度」篩選後隨機抽題，同一輪不重複，抽完自動重置 |
| 網頁輸入答案 | 作答區文字框，即時字數統計，可選 22 分 30 秒或 15 分鐘倒數計時 |
| 送出後評分並給完整答案建議 | 0–10 分，採普考取向之寬鬆計分（答題架構符合即給 5 分基本分），逐項列出命中與漏答之得分要點，並附法源與完整參考答案 |
| 接續下一題或停止 | 「下一題」／「結束並檢視紀錄」，結束後可匯出 PDF |
| 依考點法規練習 | 依 27 種考點法規標籤（建築法、政府採購法、都市計畫法、綠建築等）指定出題 |
| 錯題重練 | 曾經未達 7 分的題目自動進入錯題本，可指定只重出這些題目 |
| 複習用 | 練習紀錄與錯題本存於瀏覽器本機，可接續；結束畫面統計平均分與最常漏答要點 |

## 二、檔案結構

```
.
├── index.html                              單一檔案前端（HTML + CSS + JS，校徽以 data URI 內嵌，無相依套件與外部圖檔）
├── moex_construction_law_bank_104-115.json 題庫：49 題，含題目、法源、參考答案、得分要點、評分關鍵詞
├── moex_construction_law_answers_104-115.docx  參考答案彙編（Word，供離線閱讀與列印）
└── README.md
```

`index.html` 載入題庫時會依序嘗試 `moex_construction_law_bank_104-115.json` 與 `data/bank.json`，兩種放置方式皆可運作。

## 三、部署到 GitHub Pages

### 方式甲：網頁介面（不需安裝 git）

1. 進入倉庫，點 **Add file → Upload files**，把 `index.html`、`README.md` 與題庫 JSON 一起拖進去，按 **Commit changes**。校徽已以 data URI 內嵌於 `index.html`，不需另外上傳圖檔。
2. 點 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 Save。
3. 等 1 至 2 分鐘，網址為 `https://<您的帳號>.github.io/moex-construction-law/`，把這個網址給學生即可。

### 方式乙：命令列

```bash
cd <本專案資料夾>
git init && git add -A
git commit -m "普考營建法規概要複習系統"
git branch -M main
git remote add origin https://github.com/<您的帳號>/moex-construction-law.git
git push -u origin main
```

推送後同樣到 **Settings → Pages** 啟用。

### 本機測試

```bash
python3 -m http.server 8000
```

再開 `http://localhost:8000`。**請勿直接雙擊 index.html**，瀏覽器的檔案安全限制會使題庫 JSON 讀取失敗。

## 四、評分機制與其限制

本版採「要點關鍵詞比對」評分，完全在學生瀏覽器內執行，不傳送任何資料到外部。

演算法為：每題預先定義 5 至 7 項得分要點，每項要點由若干關鍵詞群組成（同一群內為同義詞，命中其一即算），命中群數達該要點門檻即視為答出該要點。計分採普考取向之寬鬆標準：答案達 60 字以上且至少命中一項得分要點者，視為答題架構符合，先給 5 分基本分，其餘 5 分依「命中要點數 ÷ 總要點數」比例累加，四捨五入後即為該題得分；未達架構門檻者，以「命中比例 × 4」計分，答案少於 30 字最高 1 分。此一設計使有寫出法源與基本架構的學生即可穩定取得及格水準，避免因要點未齊而反覆得低分致失去信心。評語一律以指導語呈現，直接指出下一步應補強之處。比對前會將全形轉半形、去除空白與標點，並同時接受阿拉伯數字與中文數字之條號寫法。

**限制必須讓學生知道**：本法只能判斷「有沒有寫到關鍵概念」，無法判斷論述是否通順、推理是否正確、有無自相矛盾，也無法辨識學生把關鍵詞硬湊上去的情形。它的定位是自我檢核工具，不是閱卷。實際申論題閱卷仍重視結構、論理與文字表達。

若日後要換成大型語言模型評分，只需替換 `index.html` 中的 `grade()` 函式，改為呼叫您自架的 API 代理（例如 Cloudflare Workers 免費方案），金鑰放在代理端而不放在網頁。題庫的 `scoring_points` 與 `reference_answer` 欄位可直接作為評分提示詞的評分基準，資料結構不必改動。

## 五、題庫資料結構

題庫 JSON 的 `questions` 陣列，每題欄位如下：

| 欄位 | 說明 |
|---|---|
| `id` | 題目識別碼，格式為「民國年-題號」，如 `104-1` |
| `year_roc` / `question_no` / `points` / `type` | 年度、題號、配分、題型 |
| `question` | 題目全文 |
| `law_tags` | 考點法規標籤 |
| `source_pdf` | 考選部原始 PDF 網址 |
| `legal_source` | 參考答案所引之法規名稱、條號與版本 |
| `reference_answer` | 參考答案全文，段落以空行分隔 |
| `scoring_points` | 得分要點（供人閱讀） |
| `scoring_keywords` | 評分用關鍵詞群，含 `label`、`groups`、`min` |
| `graded` | 是否已建立參考答案，決定該題是否納入可評分題庫 |

104 至 115 年全部 49 題均已建立參考答案、得分要點與評分關鍵詞，`graded` 皆為 `true`。日後擴充其他考試（高考三級「營建法規」、地方特考四等）時，只需在 `questions` 陣列新增題目並補齊上述欄位即可，前端無須修改。

## 六、法規時效與年度更新

題庫 JSON 的 `meta.last_reviewed` 記錄最後校對日期。建議每年考季前執行一次更新作業：至考選部考畢試題查詢平臺下載當年度試題，新增題目並撰寫參考答案；同時就既有題目所引條文至全國法規資料庫比對是否修正，若有修正應同步更新 `legal_source` 與 `reference_answer`，並在答案中並陳新舊規定。本題庫已有實例：105 年第四題所問候選綠建築證書效期，命題當時為五年，現行規定已改為與建造執照效力連動。

## 七、資料來源與免責

題目來源為考選部考畢試題查詢平臺。參考答案之法條係逐條查證自全國法規資料庫、內政部主管法規共用系統與行政院公共工程委員會主管法規共用系統，並於各題標明條號與版本；法條以現行版本為準，命題當年版本有實質差異者於答案中另行標註。

本科目 104 至 115 年均為純申論題型，考選部並未公布申論題標準答案。本系統之參考答案與分數為教學用途之研判，非官方標準答案。
